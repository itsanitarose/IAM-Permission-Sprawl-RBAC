# 02. RBAC Design

## 1. Proposed RBAC Model

After reviewing the job descriptions, I designed four roles to replace individually assigned permissions with **Role-Based Access Control (RBAC)**.

| Role | Assigned Permissions |
|---|---|
| Billing Clerk | Create invoices, Edit patient billing details |
| Billing Supervisor | Create invoices, Edit patient billing details, Approve refunds |
| Finance Manager | Approve payments, Export all billing data |
| IT Support | System admin, restricted to authorised technical tasks |

Each role would be managed through a dedicated security group rather than granting permissions individually.

## 2. Proposed Security Groups

| Security Group | Role |
|---|---|
| `SG_Billing_Clerk` | Billing Clerk |
| `SG_Billing_Supervisor` | Billing Supervisor |
| `SG_Finance_Manager` | Finance Manager |
| `SG_IT_Support` | IT Support |

## 3. Design Considerations

- **Least Privilege**  
  Each role receives only the permissions necessary for its documented responsibilities.

- **Unassigned Permission**  
  I excluded **Create new payee** because none of the supplied job descriptions requires it. I would confirm with Finance who should own this permission before assigning it.

- **Business Validation**  
  The proposed roles and permissions would need approval from business owners before implementation.
